# Демо: погода на модуле FG22 с экраном

Pico W на MicroPython сама берёт погоду с wttr.in и температуру дома из Home Assistant, рисует карточку и по проводам SWD записывает её в RAM устройства. Устройство выводит карточку на экран. ПК нужен только для заливки.

![карточка](card-preview.png)

Когда обновляется:

- **при подаче питания на Pico** — всегда, сразу после старта. Если Wi-Fi или погода ещё недоступны, повтор каждые 20 с, пока не получится;
- в :00 и :30 по варшавскому времени. После ошибки повтор через 2 минуты;
- по кнопке «Обновить» на веб-странице `http://<IP Pico>/`. IP печатается в консоль при старте, сейчас `192.168.31.147`.

Светодиод на Pico: 5 быстрых миганий при включении, потом мигает всё время, пока идёт обновление (около 5–10 с; сама перерисовка экрана на устройстве идёт ещё ~40 с).

## Что где

| Папка | Что внутри |
| --- | --- |
| `pico/` | всё, что заливается на Pico W: `main.py`, `pico_weather.py` и модули |
| `pico/secrets.py` | Wi-Fi и токен Home Assistant. В git не попадает. Шаблон — `secrets_example.py` |

| `tools/` | заливка на Pico, превью карточки, прошивка информера |

## Кнопки: что зажимать и когда

У Pico W **нет кнопки сброса**. Есть одна кнопка — **BOOTSEL** (белая, на плате).

| Что надо | Кнопка |
| --- | --- |
| залить или обновить наши файлы (`pico/`) | **ничего не зажимать** |
| поставить или переставить сам MicroPython | **зажать BOOTSEL** при втыкании USB |
| «сбросить» Pico | вынуть и вставить USB, без кнопок |

Если при втыкании появился диск **RPI-RP2**, а COM-порта нет, значит Pico в режиме BOOTSEL: кнопку держали, или на плате нет MicroPython. Тогда делайте шаг 1 или просто вставьте USB заново без кнопки.

## Заливка

### 1. MicroPython (один раз, или если на диске RPI-RP2)

1. Вынуть USB из Pico.
2. Зажать **BOOTSEL** и, не отпуская, вставить USB. Отпустить.
3. Появится диск `RPI-RP2` (у нас обычно `D:`).
4. Скопировать на него `demo\micropython\rp2-pico-w-latest.uf2`:

   ```powershell
   Copy-Item demo\micropython\rp2-pico-w-latest.uf2 D:\
   ```

5. Диск пропадёт сам, Pico перезагрузится, появится COM-порт (у нас `COM8`).

Файлы, залитые раньше, при этом обычно сохраняются. Если после шага 1 карточка не идёт — сделайте шаг 2.

### 2. Наши файлы (после любой правки в `pico/`)

Кнопок не нажимать, Pico просто воткнута в USB.

1. Если `pico\secrets.py` нет — скопировать `secrets_example.py` в `secrets.py` и вписать SSID, пароль и токен HA.
2. Узнать порт:

   ```powershell
   [System.IO.Ports.SerialPort]::GetPortNames()
   ```

3. Залить (из корня проекта `e-ink`):

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File demo\tools\pico_upload.ps1 -Port COM8
   ```

Скрипт сам останавливает работающий `main.py` (Ctrl-C), заливает все файлы, запускает `import pico_weather` и ждёт до 90 с. Успех — в конце лога:

```
WiFi: connected, IP 192.168.31.147
send_card: ok 21:32
boot update: ok
=== send_card seen: check the tag for the card ===
```

У каждого файла должно быть `Uploaded …: OK`.

После заливки Pico сразу работает сама. Дальше её можно питать от любого USB — ПК не нужен.

### 3. Прошивка информера (только если менялась `tag/main.c`)

Нужен отдельный отладчик (Pico с debugprobe) и компилятор в `tools\gcc` — см. корневой `README.md`.

```powershell
demo\tools\flash-card.cmd
```

## Если не работает

| Что видно | Что делать |
| --- | --- |
| `No REPL prompt on COM8` | вынуть и вставить USB (без кнопки), запустить заливку ещё раз |
| нет COM-порта, есть диск `RPI-RP2` | Pico в BOOTSEL: шаг 1 или переткнуть USB без кнопки |
| `Uploaded …: FAIL` | в логе ниже будет `Traceback` с причиной |
| `ERROR: cannot connect to …` | Wi-Fi: SSID и пароль в `pico\secrets.py`. Pico W видит только 2,4 ГГц |
| `ERROR: ... SWD ...` | устройство без питания или не подключены провода SWD |
| «Дома (HA)» на странице: `нет токена` | вписать `HA_TOKEN` в `pico\secrets.py` и залить заново |

## Как устроено

### Провода Pico W → модуль FG22

| Pico W | Модуль FG22 |
| --- | --- |
| GP2, ножка 4 | SWCLK |
| GP3, ножка 5 | SWDIO |
| GND | GND |

Подробно — `docs\pins.md` в корне.

### Модуль FG22 (`tag/main.c`)

При старте прижимает линии панели к нулю и ждёт в цикле:

- `REQ_FLAG` = `0x20000100` — Pico ставит не ноль, устройство сбрасывает и рисует;
- `CARD_RAM_BLACK` = `0x20001000`, `CARD_RAM_RED` = `0x20002600` — две плоскости карточки по 5624 байта;
- `MARK` = `0x20000000`: 30 — флаг увиден, 31 — перерисовка идёт, 32 — готово.

Если Pico выключена, на экране остаётся последняя картинка.
