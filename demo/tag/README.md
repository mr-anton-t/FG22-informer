# Тест панели

Рисует три полосы: чёрная, белая, красная. Ногу 6 чипа не трогает: куда она идёт, ещё не известно. Питание панели тоже не включает. Если контакты 15 и 16 шлейфа сейчас без питания, картинка не сменится.

| Шлейф | Сигнал | Нога чипа |
| --- | --- | --- |
| 9 | BUSY | 7, PC06 |
| 10 | RST | 5, PC04 |
| 11 | D/C | 4, PC03 |
| 12 | CS | 3, PC02 |
| 13 | SCL | 2, PC01 |
| 14 | SDA | 1, PC00 |

Собрать, когда компилятор лежит в `tools/gcc`:

```
demo\tag\build.cmd
```

Прошить, питание и SWD как для заглушки:

```
tools\flash-probe.cmd -Image demo\tag\test.hex
```

Успех записи — `Flash ok`. Успех картинки — полосы на экране. Если экран молчит, а на ноге 4 чипа (D/C) мультиметр ловит медленные переключения, прошивка жива, панель не отпустила BUSY. Если и этого нет, панель скорее всего без питания.
