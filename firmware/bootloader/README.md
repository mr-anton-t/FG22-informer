# Первый образ

`stub.hex` — не бутлоадер OpenEPaperLink и не образ Solum. Это короткий старт для EFR32FG22: стек на вершине 32 КБ RAM, запрет прерываний и вечный цикл. Ноги дисплея и радио он не трогает.

Готовый бутлоадер OEPL сюда не класть, пока нет своей распиновки. Образ Solum на эту плату не прошивать.

Запись, уже после unlock:

```text
tools\flash-btl.cmd
```

Пять попыток, пауза 5 секунд. После успешной записи попытки прекращаются. Скрипт сам чип не разлочивает и flash не стирает.
